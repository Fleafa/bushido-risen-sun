# About This Site
This site is auto-generated from what I hope will become the source for Bushido rules, hosted on GitHub, and therefore can form a single source of truth for community app projects.

> [!NOTE]
> The source files are created using the Obsidian editor for Markdown, and make use of YAML frontmatter for supporting file properties.
> My intention is to use YAML as the format for all Ki Feats, Unique Effects, and Profiles.
> YAML is easily human-readable and, as a superset of JSON, can be used in community apps without difficulty.

This site is intended as both a simple supporting resource for discussion and games, and as an example of what can be done with the source rules. I look forward to seeing what better programmers can do. Check out the tools section of the Bushido Discord server if you want to know more.

Use the search function. It is very good!
