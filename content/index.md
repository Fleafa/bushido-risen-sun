# About This Site
This site is auto-generated from what I hope will become the source for Bushido rules, hosted on GitHub, and therefore serving as a single source of truth for community app projects.
It currently covers the [[Rulebook/Contents|Rulebook]], [[Feats/|Feats]], [[Tournament Pack/Contents|Tournament & Scenario Pack]], and [[FAQ/index|Official FAQ]].

The source files are created using the Obsidian editor for Markdown, and make use of YAML frontmatter for supporting file properties.
This site is intended as both a simple supporting resource for discussion and games, and as an example of what can be done with the source rules. I look forward to seeing what better programmers can do. Check out the tools section of the Bushido Discord server if you want to know more.

> [!tip]
> Use the search function. It is ***very*** good!

Consider this an open beta test for the time being. I have a few things I want to improve, such as better navigation, mobile navigation, & more backlinks.

-Ben.
